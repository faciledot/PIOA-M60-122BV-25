2. Функциональность проекта.

Проект реализует in-memory базу данных для каталогизации MIDI-клавиатур.

В проекте реализованы возможности 

&#x09;1) Добавления записей.

&#x09;У клавиатур есть параметры, такие как id, название компании-производителя, кол-во клавиш (от 1 до 88) , цена , наличие пэдов.

&#x09;2) Просмотра всех записей.

&#x09;3) Поиска с фильтрацией с любым сочетанием параметров.

&#x09;4) Обработка ошибок ввода (Некорректный ввод чисел, отрицательная цена, количество клавиш вне диапазона 1–88, неверное значение поля пэдов, дублирование ID, пустое название компании.)

Для запуска проекта нужно открыть терминал, перейти в корневую папку src/db, выполнить команду python -m src.db.
